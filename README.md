# 🫀 CardioSense AI

### Intelligent Heart Attack Prediction & Preventive Healthcare Platform

AI • Machine Learning • Flask • Healthcare Analytics

CardioSense AI is a smart healthcare prediction platform designed to detect potential heart attack risks using Machine Learning and medical data analysis.

The system analyzes patient health parameters and provides intelligent predictions, helping users understand possible cardiovascular risks before serious complications occur.

Built with AI-driven healthcare technology, the platform focuses on early detection, preventive care, and accessible health assistance.

---

# 🌟 Vision

Healthcare should not begin after a medical emergency.

CardioSense AI aims to support proactive healthcare by using Artificial Intelligence to identify heart-related risks early and encourage preventive medical action.

# 🧠 Machine Learning Pipeline

The project follows a complete ML workflow:

### 📍 Data Collection

Patient healthcare dataset containing:

- Age
- Sex
- Cholesterol
- ChestPainType
- RestingBP
- FastingBS
- MaxHR
- ExerciseAngina
- Oldpeak
- ST_Slope
- HeartDisease

---

### 📍 Data Preprocessing

- Handling missing values
- Feature selection
- Data cleaning
- Label encoding

---

### 📍 Model Training

Machine Learning algorithms used:

- Random Forest Classifier
- Logistic Regression

---

### 📍 Prediction Generation

The trained model predicts:

- Low Heart Attack Risk
- Moderate Heart Attack Risk
- High Heart Attack Risk
